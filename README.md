  Автотесты для UI сервиса Stellar Burgers
Этот проект содержит автоматизированные тесты для веб-интерфейса сервиса "Stellar Burgers". Тесты проверяют основную функциональность приложения с использованием паттерна Page Object Model (POM) и поддерживают запуск в браузерах Chrome и Firefox.

  Ключевые функции
Тестирование основных элементов интерфейса
Проверка функциональности конструктора бургеров
Тестирование ленты заказов
Поддержка кросс-браузерного тестирования (Chrome, Firefox)
Интеграция с Allure для генерации отчетов


  Основная функциональность
Переход в конструктор по клику на кнопку "Конструктор"
Переход в ленту заказов по клику на кнопку "Лента заказов"
Открытие деталей ингредиента по клику
Закрытие модального окна по клику на крестик
Увеличение счетчика ингредиента при добавлении в заказ

  Лента заказов
Увеличение счетчика "Выполнено за всё время" при создании заказа
Увеличение счетчика "Выполнено за сегодня" при создании заказа
Появление номера заказа в разделе "В работе" после оформления

  Особенности реализации
Page Object Pattern: Элементы страниц описаны в отдельных классах
Кросс-браузерное тестирование: Поддержка Chrome и Firefox
Изолированные тесты: Каждый тест независим от других
API для управления данными: Создание и удаление тестовых пользователей через API
Allure-отчеты: Детальные отчеты с шагами тестов
